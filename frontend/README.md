# frontend

React 또는 Next.js 기반 PWA. 백엔드 API(`backend/app/api`)를 호출해 오늘의 뉴스를 보여준다.

```
frontend/
└── src/
    ├── components/  # 재사용 UI 컴포넌트 (뉴스 카드, 카테고리 탭 등)
    ├── pages/        # 화면 단위 (메인, 상세, 설정)
    └── styles/       # 스타일
```

## 화면 구성 (초안)

- 메인 화면: 오늘 날짜 + 카테고리 탭 + 뉴스 카드 리스트
- 상세 화면: 요약 전문 + 키워드 + 원문 링크
- (확장) 설정 화면: 관심 카테고리 선택, 알림 설정
