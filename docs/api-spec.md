## 엔드포인트 (초안)

| Method | Path | 설명 | 담당 |
|---|---|---|---|
| GET | /news | 오늘의 뉴스 목록 조회 (카테고리 필터 가능) | B |
| GET | /news/{id} | 뉴스 상세(요약 전문, 키워드, 원문 링크) 조회 | B |
| GET | /categories | 카테고리 목록 조회 | B |
