# 뉴스 요약 앱 — 프로젝트 기획서

2인 개인 포트폴리오 프로젝트 (발표 없음)

---

## 1. 프로젝트 배경 / 문제 정의

바쁜 아침, 여러 언론사 앱과 사이트를 오가며 오늘의 주요 뉴스를 확인하는 건 번거롭고 시간이 걸린다. 대부분의 뉴스 앱은 원문을 그대로 나열할 뿐, "오늘 꼭 알아야 할 내용"을 짧고 빠르게 정리해주지는 않는다.

이 프로젝트는 매일 자동으로 뉴스를 수집·분류·요약해, 사용자가 아침에 앱을 켜자마자 그날의 핵심 뉴스를 몇 분 안에 훑어볼 수 있게 하는 것을 목표로 한다.

---

## 2. 서비스 개요

**한 줄 정의:** 과학기술정보통신부의 최신 IT 보도자료를 자동 수집하고, 핵심 사실을 짧게 요약해 보여주는 PWA 앱

**핵심 가치:**
- 여러 언론사를 돌아다닐 필요 없이 한 곳에서 확인
- 원문 대신 짧은 요약으로 빠르게 파악
- 카테고리별로 정리되어 관심 분야만 골라 볼 수 있음
- 원문 전문의 핵심 결정·수치·일정·영향을 짧은 브리핑으로 확인
- 원문 링크를 통해 공식 자료 전체를 바로 확인

---

## 3. 타겟 사용자

- 출퇴근/등교 전 짧은 시간에 뉴스를 훑어보고 싶은 사람
- 특정 카테고리(경제, IT 등) 뉴스만 골라 빠르게 보고 싶은 사람
- 여러 뉴스 앱을 설치하기보다 가볍게 웹으로 확인하고 싶은 사람

---

## 4. 핵심 기능 목록

### MVP (반드시 구현)
- 과학기술정보통신부 보도자료 자동 수집 (RSS → 상세 페이지·첨부 전문)
- 1차 데이터 범위: IT 카테고리
- 기사별 짧은 요약 (LLM 기반)
- 오늘의 뉴스 목록/상세 화면 (PWA)
- 원문 링크 연결
- 매일 오전 7시 브리핑 갱신, 오후 1시 보강 수집

### 확장 기능 (여유 있을 때)
- 웹 푸시 알림 / 이메일로 "오늘 요약 도착" 알림
- 키워드 트렌드 시각화 (오늘 많이 언급된 키워드)
- 검색 기능 (키워드로 지난 뉴스 검색)

---

## 5. 기술 아키텍처

```
[과학기술정보통신부 보도자료 RSS]
        ↓
[상세 페이지·첨부 PDF/HWPX 전문 추출]
        ↓
[전처리 - 정제, 중복제거, 필터링]
        ↓
[LLM 요약 + 카테고리 분류]
        ↓
[DB 저장]
        ↓
[백엔드 API]
        ↓
[프론트엔드 - PWA]
```

- GitHub Actions cron이 KST 오전 6시에 수집·요약을 실행해 오전 7시 브리핑을 준비하고, 오후 1시에 새 자료를 보강 수집
- 전처리 단계에서 데이터 품질 관리 (중복 기사, 광고성 텍스트 제거)

---

## 6. 기술 스택

| 영역 | 스택 |
|---|---|
| 프론트엔드 | React 또는 Next.js (PWA) |
| 백엔드 | FastAPI (Python) |
| DB | PostgreSQL |
| AI/요약 | LLM API (요약, 카테고리 분류) |
| 스케줄러 | GitHub Actions cron |
| 뉴스 소스 | 과학기술정보통신부 보도자료 RSS, 상세 페이지, 공개 첨부 PDF/HWPX |
| 배포 | Vercel(프론트) + Render/Railway(백엔드) |
| 협업 | GitHub Organization, Google Drive |

---

## 7. 화면 구성 (초안)

- **메인 화면**: 오늘 날짜 + 카테고리 탭 + 뉴스 카드 리스트(제목, 요약 미리보기, 언론사)
- **상세 화면**: 요약 전문 + 키워드 + 원문 링크
- **(확장) 설정 화면**: 알림 설정

## 10. 기대 효과 / 차별점

- 원문 나열형 뉴스 앱과 달리, **요약 중심**이라 짧은 시간에 소비 가능
- "매일 자동으로 준비되는" 파이프라인 자체가 실무형 시스템 설계 경험으로 어필 가능
- 데이터 수집→전처리→AI 처리→저장→서빙까지 이어지는 전체 파이프라인을 두 사람이 나눠 구현하며 각자의 기여를 명확히 문서화할 수 있음
